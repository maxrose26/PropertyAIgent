## A. Pilot objective

Test whether the same qualified evidence produces more useful acquisition decisions than basic planning search: meaningful opportunity hypotheses, non-obvious relationships, buyer-specific fit, disciplined uncertainty and actionable next diligence. Later test whether bounded economic reasoning improves understanding of assumptions and sensitivities. The experiment is about decision support, not proof of available land, transaction success, current council truth or national coverage.

## N. Freshness, source and uncertainty

Reuse B2.1 exact-application freshness presentation and B1 evidence containment. Distinguish source fact date, successful verification time, capture time and evaluation time. Freeze the evaluation clock and record it. Preserve an additional dated contradiction overlay where independently retained evidence differs from stored facts; do not mutate stored facts.

- VERIFIED AS OF [DATE]: existing verified_as_of presentation; not a guarantee today.
- VERIFICATION UNAVAILABLE: absent/unusable successful verification or unsupported route; retain accepted evidence.

Current B2.1 also has requires_refresh, verified_within_policy, conflicting and currently_unverifiable states. Reuse them rather than inventing freshness scoring. Absent fields are not verified null, zero or negative truth. None of these qualifications automatically removes a case from every pilot experiment.

## O. Acquisition Intelligence test framework

Compare equal evidence and frozen dates across three views: (1) basic planning search/filter/list with source qualifications; (2) existing deterministic family/matcher/Specification028 output; (3) a later separately authorised intelligence hypothesis/explanation output. This separates benefits already delivered by deterministic matching from incremental AI value. No model is called in this slice.

Minimum output rubric: opportunity hypothesis; why potentially actionable; why now with dated evidence or explicit unknown; buyer fit and causal rule; source support; conflicts/unknowns; next diligence. No availability claim from planning permission. No confident “why now” from a stale timestamp or absence of updates.

Use the same evidence budget, no extra external evidence for the intelligence arm, randomised/blinded output order and recorded review time. REVIEW appoints human acquisition reviewers; independently label investigate/not-investigate/uncertain with reasons and confidence, then adjudicate disagreements. Model outputs must never become their own labels. Retain uncertain labels and report adjudication disagreement. Score unsupported claims as errors even if a reviewer likes the prose.

## Q. Economic/Investment Intelligence MVP hypothesis

Propose a later **3–5-case, scenario-only** experiment selected from qualified packets, including one insufficient-evidence case. Can a concise assumption ledger and deterministic sensitivity calculation help reviewers identify the decisive viability questions faster than a static evidence summary? This is not a real residual valuation or investment recommendation.

Separate four types: SOURCE FACT (dated/scoped/cited); CALCULATED VALUE (formula, units and input lineage); USER ASSUMPTION (owner/date/range); AI INFERENCE (reasoned hypothesis and uncertainty). A missing cost, tenure split, unit area or obligation is not zero. No generic market rate or return threshold supplied by the model counts as a fact. If REVIEW has not supplied/approved scenario inputs, deliver the information-needs checklist only.

Use supported units/tenure/stage/location; list land, build, abnormal, fees, finance, programme and obligations as relevant assumptions. Test which stated changes in value/cost/programme alter the scenario result. Use one declared calculation convention, prevent double counting, reconcile units/currency/dates and compare calculations with an independent deterministic oracle. No giant appraisal system, comparable engine, tax/legal advice or fund model. Any decision about whether a real site is economically attractive remains blocked until appropriate market/obligation evidence exists.

The existing roadmap's Market Intelligence prerequisite remains for real development appraisal. The proposed scenario experiment is a separately reviewed learning exercise, not permission to bypass that prerequisite. Economic/AI implementation and model execution need another decision.

## R. Proposed measurable criteria (no invented pass thresholds)

| Dimension | Measure and denominator |
|---|---|
| Precision | Reviewer-approved worthwhile investigations / surfaced hypotheses; also report rejected and uncertain labels |
| Omission | Missed reviewer-labelled positives within the sealed sample / all sample positives; not population recall |
| Novelty | Evidence-supported useful hypotheses not found in baseline review / adjudicated useful hypotheses; distinguish new insight from new wording |
| Buyer relevance | Agreement with buyer-specific adjudication; justified pairwise preference changes; insufficient-evidence rate |
| Explanation | Claim-to-evidence traceability and correct causal reason; reviewer ability to state why surfaced |
| Evidence discipline | Unsupported factual/availability claims, hidden uncertainty, wrong-scope attribution, false freshness, known contradiction handling |
| Efficiency | Time per case and time to defensible shortlist at comparable decision quality; reviewer effort to verify/correct outputs |
| Economics | Calculation agreement, correct assumed/factual separation, sensitivity-driver identification, usefulness of next evidence request |

Report numerator/denominator, eligibility, exclusions, abstentions, buyer/council breakdown and reviewer disagreement. Do not conceal hard cases by excluding them from the reported denominator. Freeze commercial success thresholds with REVIEW before holdout evaluation. Evidence/privacy invariants remain safety gates regardless of commercial metrics: no invented facts, no cross-buyer leakage, no unqualified currentness or residual quantities.
